# Glossary

| Term | Meaning |
|---|---|
| Agent | A model-driven workflow that can choose and call application tools under explicit limits. |
| Chunking | Splitting source material into smaller passages for retrieval and model context. |
| Embedding | A vector representation of text meaning, used to find semantically similar passages. |
| Evaluation set | A curated set of inputs with expected evidence or outcomes, used to measure changes. |
| MCP | Model Context Protocol, a standard for assistants to discover and call tools or read resources. |
| Observability | Traces, metrics and logs that help explain system behaviour and performance. |
| RAG | Retrieval-augmented generation: find relevant source passages, then ask a model to answer from them. |
| Vector store | A database component for storing embeddings and retrieving nearby vectors. |
