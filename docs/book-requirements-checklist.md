# Book requirements checklist

This is an implementation audit of the supplied 87-page *Building AI with Java & Spring Boot* book, not a list of topics merely mentioned in the source. `Done` means there is implementation evidence in this repository. `Partial` means a useful local slice exists but the named workflow is missing or materially simplified. `Open` means the requirement has not been implemented. External-service checks are not counted as verified when the service was unavailable. Per the [showcase completion scope](showcase-scope.md), these book-depth gaps are optional stretch work unless they block a documented basic local demo.

## Environment-dependent gates

- PostgreSQL/pgvector and Ollama integration tests need those services running with the documented models.
- Docker is reachable with elevated access; DocuMind image/Compose was built and manually smoke-tested. The default sandbox cannot reach its named pipe, and Docker/CI execution is not yet automated across all projects.
- ReviewPilot's GitHub API workflow needs an explicitly configured GitHub App and secrets; unit tests must continue to use recorded fixtures or fakes.
- VoiceNotes's audio path needs a local ffmpeg binary and whisper.cpp model; cloud transcription requires opt-in credentials.
- GitHub Actions and Dependabot configuration can only be observed running after the local project is pushed to an authorised repository. The user selected a local project and no push has been authorised in this thread.
