# Inspiration repositories

This directory records the repositories listed in Appendix A of the supplied book. The book captured descriptions, stars and licence metadata from GitHub on 17 October 2026. Those counts and licence detections are a dated snapshot; open the source repository and read its actual licence before reusing code. The portfolio uses these projects as references and does not copy their source.
